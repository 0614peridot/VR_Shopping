### UI Type

- **Controls guide:** Movement, camera-look, and product-inspection instructions.

- **Shopping cart/bag indicator:** Cart icon, item-count badge, and a button that opens the cart.
- **Shopping cart/bag panel:** Scrollable product list, product names, prices, empty-cart message, running total, and close button.
- **Product focus/inspection panel:** Product name, price, rotation instructions, **Add to Cart** button, and **Exit** button.
- **Product focus feedback:** Visual highlight showing which product is currently selected or being inspected.
- **Checkout prompt:** Contextual button shown when the user approaches the checkout clerk.
- **Checkout review panel:** Scrollable order summary, empty-cart state, total price, **Shop More** button, and **Check Out** button.
- **Checkout confirmation:** Temporary thank-you message shown after checkout is completed.
- **Personal shopper conversation panel:** Shopper prompt with primary and secondary response buttons.
- **Personal shopper speech bubbles:** Welcome/ambient messages and contextual comments about the selected product.


## Shopping User Flow

### Current Version

1. **Enter and explore the store**
   - The user starts outside the store and moves with the desktop movement controls.
   - The controls guide explains movement, camera look, and product selection.

2. **Optionally interact with the personal shopper**
   - Approaching and selecting the personal shopper opens a conversation panel.
   - The user can ask for outfit help or decline.
   - If accepted, the shopper follows the user and displays contextual product comments.
   - The user can later choose to keep receiving help or stop the shopper from following.

3. **Select a product**
   - The user clicks a selectable garment, shoe, or bag.
   - The selected product receives visual focus feedback and moves into the inspection view.
   - The product panel displays its name and price.

4. **Inspect the product**
   - The user clicks and drags to rotate the focused product.
   - The user can exit inspection and return the product to its original display position.

5. **Add the product to the shopping cart/bag**
   - The user selects **Add to Cart** from the product inspection panel.
   - The cart item-count badge updates.
   - The cart panel can be opened to review product names, individual prices, and the running total.

6. **Continue shopping or approach checkout**
   - The user can repeat the select, inspect, and add-to-cart flow for more products.
   - When the user approaches the checkout clerk, a checkout prompt appears.

7. **Review the order**
   - Opening checkout displays a scrollable list of cart items and the total price.
   - If the cart is empty, an empty-cart message is shown.
   - The user can choose **Shop More** to close checkout and return to the store.

8. **Complete checkout**
   - The user selects **Check Out** to complete the purchase.
   - The cart is cleared and a temporary thank-you confirmation appears.
   - The user can then continue exploring and shopping.
