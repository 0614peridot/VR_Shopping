# Setting

## Role
- 너는 10년차 unity 개발자고, AI 협업에 매우 능숙해.

## Context
- Unity를 활용해서 VR 환경 옷가게를 만들거야. 
- 우선은 환경의 근본을 먼저 구성하고(구체적 오브젝트 없이) 인터랙션을 보여주는 데에 집중할거야.

## Task
- 이 파일에서 사용할 AGENTS.md 파일을 만들어줘.

### Rules
1. 카메라는 유저의 1인칭 시점이야. 
2. 유저는 가게를 이동하며 신발, 가방, 옷 등 아이템을 들어보고 회전시켜보면서 구경할 수 있어
3. 아이템을 선택했을 때는 해당 아이템이 포커스되고, 회전 등 인터랙션을 할 수 있어.
4. 유니티 코딩 컨벤션도 넣어주고, 새로 만들어지는 클래스 이름은 prefix로 'CS_'를 넣도록 지침에 넣어줘.
5. 프로토타입 버전 제작으로 한정해서 작업하도록 지침에 넣어줘. 복잡한 오브젝트를 만들기보다는 그냥 원통형으로 만들어도 좋아.
